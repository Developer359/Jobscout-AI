Overview

JobScout-AI is a comprehensive command-line tool that automates the job search process by matching candidate CVs against real-time job postings. It utilizes a robust pipeline consisting of document parsing, Vector Language Model (VLM) understanding, vector embeddings (Chroma DB), and agentic search generation.

Installation

Follow these steps to set up JobScout-AI locally on your machine.

Dependencies (requirements.txt)

Create a file named requirements.txt in your project root and copy-paste the following exact libraries that the project needs:

pymupdf
google-genai
chromadb
langchain-chroma
langchain-huggingface
langchain-text-splitters
python-jobspy
pandas
python-dotenv
sentence-transformers

Step-by-step Setup

# 1. Clone the repository
git clone https://github.com/yourusername/jobscout-ai.git
cd jobscout-ai

# 2. Create a virtual environment (highly recommended)
python -m venv venv

# On Windows use: 
venv\Scripts\activate
# On Mac/Linux use: 
source venv/bin/activate 

# 3. Install the exact required packages
pip install -r requirements.txt

Configuration

Create a .env file in the root directory (jobscout-ai/) and add your private API keys:

GEMINI_API_KEY=your_gemini_api_key_here

Usage

To run the full pipeline, place your target candidate CVs (PDFs or DOCX) into the Data/inputs/ directory.

Then, simply execute the main orchestrator script:

python main.py

The application will process the CVs, generate queries, search for jobs, and save the generated markdown reports into the Data/outputs/ directory.

1. Parser

The first step in the JobScout-AI pipeline is extracting text from candidate CVs.

Overview

This module reads `.pdf` and `.docx` files from the Data/inputs/ directory and converts them into raw text for further processing.

What is used

We utilize pymupdf for efficient and accurate text extraction from PDF documents, and langchain-text-splitters for chunking.

2. VLM Analysis

Once the text is extracted, it is analyzed by a Vector Language Model (VLM).

Overview

The model understands the semantic meaning of the candidate's experience, skills, and qualifications, preparing it for vectorization.

What is used

Powered by the google-genai SDK using Gemini Flash-Lite to process and structure the unstructured CV data.

3. Chroma Store

The structured data is embedded and stored in a local vector database.

Overview

This allows for fast semantic similarity searches when matching candidates to job requirements.

What is used

Chroma DB for local storage, and langchain-huggingface for embeddings.

4. Query Generation

The AI generates targeted job search queries based on the candidate's profile.

Overview

Instead of basic keyword searches, the agent formulates complex queries that capture the nuances of the candidate's ideal role.

5. Job Search

The generated queries are executed against real-time job boards.

Overview

The system retrieves current, relevant job postings from Indeed and LinkedIn that match the candidate's profile.

What is used

python-jobspy is used to execute web scraping tailored for job discovery, and pandas handles data structure.

Data Directory

The Data/ directory is used for local file storage and should not be committed to version control.

  • Data/inputs/: Place candidate CVs here.
  • Data/outputs/: Markdown reports are generated here.
  • Data/chroma_db/: Persistent storage for the vector database.
